## What a new session must do first

- Install openssh-client (`apt-get install -y openssh-client`), which signing needs and the environment lacks.
- Make its own signing key; it cannot add it alone, because the check reads keys from the parent commit. Dinis has not yet chosen how a new session's key is added (an ask in `status.json`): either this session adds it in a signed commit while it runs, or a person adds it and that commit is pinned in `scripts/check-signatures.mjs`'s BOOTSTRAP list.
- Set `gpg.ssh.program ssh-keygen` locally in the clone, never globally; the environment's own signer is not the agent's.

## Lessons from 19 November

- Take every time from `date -u` or the commit; times set by feel drifted up to 12 minutes and were corrected. It happened again at 14:04 and 14:07 (written as 14:10, a message as 14:09): run `date -u` just before writing a time, every time.
- A find-and-replace that asserts nothing applies nothing; every patch asserts its match.
- Test checks with bad input and assert the reason; break the check on purpose to see the tests bite.
- A date read from "N hours ago" is a guess; replace it when the source gives the time.
- An exemption keyed on indentation or depth is not keyed on the field; check the parent key.
- Records shown after their outcome was known are not forecasts; count them apart.
